# Archivos secundarios públicos

Página web para compartir trabajos interactivos mediante un enlace, sin enviar directamente el archivo de presentación.

## Acceso

La presentación publicada está disponible en GitHub Pages:

- https://7320256-arch.github.io/archivos-secundarios-publicos/

> Nota: las páginas web necesitan enviar HTML, CSS y JavaScript al navegador para funcionar. Este repositorio no ofrece un enlace de descarga de la presentación, pero el código que ejecuta el navegador nunca puede ocultarse por completo frente a alguien con conocimientos técnicos.
